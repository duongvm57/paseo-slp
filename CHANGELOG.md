## [0.1.0] - 2026-09-18

Initial public release.

### Added

- SLP role pack for Paseo: Supervisor/Lead/Peer across devin, codex, pi and
  claude provider families (claude via Agent SDK stream-json transport)
- `slp.mjs` CLI: install, upgrade, verify, uninstall, init, routes, inventory,
  agents, prepare, prepare-handoff, materialize, monitor, notebook
- `prepare` emits spawn-kit (required MCP tool signatures), orientation
  manifest (locators-only), and a carrier block injected into the child
  `initialPrompt`
- `monitor` — on-demand delta-only signal scan over agent state, git status and
  an optional read-only devin `sessions.db` probe (joined by `nativeHandle`)
- `materialize` — carry `.paseo-slp` catalog + protocol into fresh worktrees,
  rebasing absolute paths
- `notebook` — read-only locator for the active Supervisor notebook across
  worktrees of the same repository
- E2E dogfood harness (`e2e/cli.mjs`, scenarios, ledger, gate, integrity,
  evidence, report) plus `paseo-slp-onboarding` and `paseo-slp-e2e` skills
- `workspace-protocol.md` template — Human authority, routing intent,
  communication language, per-checkout notebook

### Fixed

- Session attribution in the devin probe joins `persistence.nativeHandle`
  instead of newest-session-by-cwd
- Mode source precedence: plan binding > `agent_mode` > bundle `modeId` > ask
  Human — no silent override of saved profiles
- End-turn rule applies only when all remaining work waits on armed events and
  no local action is left (fan-out is no longer cut early)
- Review checklists require exhaustive enumeration-site lists for parity claims
